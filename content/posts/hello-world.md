## 开始

这是这个博客的第一篇文章。站点用 [Hugo](https://gohugo.io/) 生成，主题是 [PaperMod](https://github.com/adityatelange/hugo-PaperMod)。

### 接下来可以做的事

- 把它推到 GitHub，用 GitHub Pages 托管
- 换个自己的域名
- 把 `hugo.yaml` 里的标题、简介、头像改成自己的

```bash
# 本地预览
hugo server -D
```

就这么开始了。
